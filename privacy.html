プライバシーポリシー

対象：FirstLight（FL-techラボの動画制作の仕組み）　制定日：2026年11月17日

1. 利用者

FirstLight は、FL-techラボの運営者本人が、自分の Google アカウントだけで使うためのアプリです。運営者以外の方が Google アカウントでログインして使うことは想定していません。

2. Google アカウントで扱うデータと権限

  • FirstLight が求める権限は、Google ドライブの drive.file（https://www.googleapis.com/auth/drive.file）だけです。
  • この権限で扱えるのは、FirstLight が作成したファイルとフォルダだけです。運営者のドライブにあるそれ以外のファイルを読んだり、変更したりすることはできません。
  • FirstLight は、作成した動画・サムネイル画像・概要欄のテキスト・処理の記録を、運営者本人のドライブに保存するためにこの権限を使います。

3. 第三者への提供

Google のユーザーデータを第三者に提供・販売することはありません。広告や分析の目的で使うこともありません。

FirstLight による Google API から受け取った情報の使用および他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

4. 保存と削除

  • 作成したファイルは、運営者本人の Google ドライブにだけ保存します。
  • 動画とサムネイル画像は、ドライブに保存してから30日たつと自動で削除します。概要欄のテキストと処理の記録は、同じ動画を二度作らないために残します。
  • ドライブへの保存に使う認証情報は、運営者が管理する非公開の設定（GitHub の Secrets）にだけ保存します。
  • 運営者は、Google アカウントの「サードパーティのアクセス」からいつでも FirstLight の権限を取り消せます。取り消すと、FirstLight はドライブにアクセスできなくなります。

5. YouTube チャンネルの視聴者の方へ

FirstLight は視聴者の方の個人情報を集めません。動画の視聴やコメントで扱われる情報は、YouTube（Google）のプライバシーポリシーに従います。

6. 変更

このポリシーを変えるときは、このページを更新し、制定日の横に更新日を書きます。

7. お問い合わせ

YouTubeチャンネル（FL-techラボ）からご連絡ください。
